# Requirements

Every requirement of {{PROJECT_NAME}} with a stable ID. Format: [conventions.md](conventions.md) §3.

- IDs never change and are never reused. A dropped requirement keeps its row with status `dropped`.
- Every requirement has a card with the same ID on the board (`docs/board/cards/`).
- `Type`: `feature`, `change`, `bug`, `data-fix`, `question`. `Status`: `agreed`, `pending`, `dropped`.
